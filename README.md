Energy-Efficient OS Scheduling Simulator is a web-based tool designed to simulate and visualize how different CPU scheduling algorithms impact system performance and energy consumption. Built using HTML, Tailwind CSS, JavaScript, and Chart.js, this simulator provides an interactive interface where users can input process details like burst time and arrival time, choose from multiple scheduling algorithms—including First-Come, First-Served (FCFS), Round Robin (RR), and a custom Energy-Aware Scheduling algorithm—and observe the execution timeline through dynamic Gantt charts. The tool calculates essential performance metrics such as turnaround time, waiting time, and total energy consumed, giving users insight into how scheduling decisions affect both speed and efficiency.

This project emphasizes the importance of energy efficiency in modern computing systems, especially in mobile and embedded environments where power conservation is critical. It is intended as an educational aid for students and developers studying operating systems, providing a hands-on way to understand and compare traditional and energy-focused scheduling strategies. The simulator's clean layout and real-time feedback make it easy to explore how changes in algorithm or process data influence system behavior. Overall, this project bridges the gap between OS theory and practical energy-aware design, highlighting the trade-offs between performance and power consumption in a visual and engaging format.
